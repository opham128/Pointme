# Assets Directory

This directory should contain the following image assets for the Expo app:

- `icon.png` - App icon (1024x1024px)
- `splash.png` - Splash screen image (1242x2436px recommended)
- `adaptive-icon.png` - Android adaptive icon (1024x1024px)
- `favicon.png` - Web favicon (48x48px)

## Quick Setup

You can generate placeholder assets using Expo's asset generator or create simple colored squares for development:

1. **For Development**: You can use any 1024x1024px image for the icon
2. **For Production**: Use proper app icons following platform guidelines

## Generating Assets

You can use online tools or Expo's asset generator:
- [App Icon Generator](https://www.appicon.co/)
- [Expo Asset Generator](https://docs.expo.dev/guides/app-icons/)

For now, you can create simple placeholder images or the app will work without them (Expo will show default icons).
